ML Based Malware Detection Using Hardware Assisted Performance Counters

Conference: IEEE ICCIT 2025

Status: Published

Authors: Rifah Nanzeeba, Mohammed Ismail Chowdhury, Pran Kanai Saha

Developed an HPC-based malware detection framework that assigns classifier weights analytically using recall-focused performance metrics and aggregates predictions through probability-based voting to produce an interpretable, confidence-guided decision.

DisBot: An Automated Medicine Dispensing Robot for Efficient Delivery

Conference: IEEE QPAIN 2025

Status: Published

Authors: Sadad Hasan, Kazi Mubashir Tazwar, Nayeemul Islam, Rifah Nanzeeba, Md. Hasan Newaz

Designed and implemented a low-cost autonomous medicine dispensing robot integrating RFID and IoT technologies, enabling real-time, patient-specific medication delivery with high accuracy and minimal human intervention.

IR-Remote Driven and Automated Light Intensity Control System Responsive to Occupancy Level

Conference: IEEE QPAIN 2025

Status: Published

Authors: Tanzim Al Mahmud, Asikur Rahman Jowel, Farhan Zawad Chowdhury, Mehedi Hasan, Rifah Nanzeeba, Imtiaj Ahmed Fahim

Designed and implemented a microcontroller-based TRIAC dimming system with IR sensor-based occupancy detection to enable automated, energy-efficient indoor lighting with manual control capability.

Pipeline for Real-Time Drowsiness Detection Using Pre-Trained CNN Model

Conference: IEEE QPAIN 2025

Status: Published

Authors: Sadad Hasan, Kazi Mubashir Tazwar, Prantik Paul, Rifah Nanzeeba

Designed a real-time driver drowsiness detection pipeline using InceptionV3-based transfer learning for eye-state classification, evaluated on mixed real-world and augmented datasets with 89.98% accuracy and validated performance under low-light and motion-blur conditions.
